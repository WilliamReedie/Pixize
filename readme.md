#### Instructions





* Install .NET runtime 8.0 if it is not installed already
* Install Pixize Installer.msi
* Open folder containing png image in command-line



* Run "C:\\Program Files\\William Reedie Pixize\\Pixize.exe" {filename}.png -s {scale factor}

or

* Run "C:\\Program Files\\William Reedie Pixize\\Pixize.exe" {filename}.png -s {scale factor}

or

* Run "C:\\Program Files\\William Reedie Pixize\\Pixize.exe" {filename}.png --scale {scale factor}



* Find the {filename}x{scale}.png file in the folder you opened before





eg. "C:\\Program Files\\William Reedie Pixize\\Pixize.exe" test.png --scale 3

will produce testx3.png





If no scale argument is provided, will default to 2x
